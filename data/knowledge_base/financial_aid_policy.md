# Northfield University Financial Aid Policy (Synthetic Demonstration Document)

> Fictional document written for the ScholarAI Workforce demo.

## 1. What Counts as Financial Need

Financial need is assessed from a household's annual income, household size,
number of dependents, the applicant's annual tuition cost, and any financial
aid the household is already receiving. The university does not require a
specific proof-of-income document format, but the Financial Aid Application
Form must report all five figures above for a need determination to be made.

## 2. Missing Financial Information

If an applicant's financial information is incomplete, the application must
not be scored on financial need using assumed or estimated figures. Incomplete
financial applications are routed to a human financial aid officer for
manual review rather than being denied or approved automatically.

## 3. Aid Stacking

Financial need scores account for financial aid the household is already
receiving from other sources; a household already receiving substantial aid
relative to its income will have a lower marginal financial need score under
this policy, all else being equal.

## 4. Verification

The Financial Aid Office may request supporting documentation (pay stubs,
tax filings) for any application before an award is disbursed, independent
of the automated evaluation described in the Scholarship Policy.
